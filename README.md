# 결혼 준비 노트

이사 · 웨딩촬영 · 결혼식 · 신혼여행 준비를 한 곳에서 관리하는 단일 HTML 체크리스트 앱입니다.

- **이사 / 촬영 / 결혼식 / 신혼여행** 4개 탭
- 페이지별 날짜와 D-day, 완료율 프로그레스 바
- 체크리스트 항목 체크·추가·삭제, 전체/할 일/완료 필터
- 참고자료와 내 메모·링크(추가·삭제)
- 촬영 레퍼런스 갤러리(사진을 누르면 크게 보기)
- JSON 백업 내보내기 / 불러오기 / 기본값 초기화
- **둘만의 비밀코드로 실시간 동기화** (Firebase Realtime Database)

## 실시간 동기화

1. 위쪽 헤더의 **🔒 동기화 안 됨** 배지를 누릅니다. (처음 열면 자동으로 코드 입력 창이 떠요)
2. 둘만 아는 **비밀코드**를 입력하고 **연결**을 누릅니다.
3. 같은 앱 주소를 연 상대가 **같은 코드**를 입력하면, 두 사람이 체크·메모·날짜를 실시간으로 함께 고칩니다.

- 코드는 이 기기의 브라우저 `localStorage`(`wp_sync_code`)에만 저장되며, 페이지·저장소 어디에도 적혀 있지 않습니다.
- 서버에는 `/rooms/<비밀코드>` 아래에 기록이 저장되고, 보안 규칙이 그 코드와 일치할 때만 읽기/쓰기를 허용합니다.
- 코드를 모르면 `PERMISSION_DENIED`가 나고, 앱은 "비밀코드가 맞지 않아요"라고 알려 줍니다.
- 동기화를 끊어도 기록은 이 기기에 그대로 남습니다(`동기화 끊기`).

모든 기록은 기기의 브라우저 `localStorage`에도 함께 저장되어, 인터넷이 없어도 그대로 열립니다.
사진은 참고용으로 앱 안에 포함되어 있습니다.
